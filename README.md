<h1 align="center">Filimin — Gamified Financial Literacy Platform 🪙🎮</h1>
<h3 align="center">HTML5 • CSS3 • JavaScript • Node.js • Firebase</h3>

<p align="center">
🚀 <b>Filimin</b> is an interactive, gamified learning platform designed to empower teenagers with solid financial fundamentals. By transforming complex economic concepts into engaging quests and quizzes, it bridges the gap between theoretical knowledge and real-world financial capability.
</p>

---


### 🚀 Key Implementations

* **Gamified Quiz Engine:** Developed a multi-level quiz architecture that breaks down complex financial modules (Budgeting, Interest, Credit Scores, and Investing) into bite-sized, interactive levels.
* **Dynamic Progress Tracking:** Designed a real-time analytics dashboard utilizing modern UI feedback loops to track user high scores, learning streaks, and milestones.
* **Secure Authentication & Storage:** Integrated Firebase Auth to handle user profiles safely, mapping individual unique IDs (`uid`) to real-time database trees to secure progress records against data tampering.
* **Responsive Interactive UI:** Crafted a clean, mobile-first, responsive user interface ensuring smooth usability across both mobile web browsers and desktop platforms.

---

### 🛠️ Tech Stack Used

* **Frontend:** HTML5, CSS3, JavaScript (ES6+) – Pure, framework-less implementation for fast loading times and native DOM manipulation.
* **Backend:** Node.js – Manages server environment routing and serves application interfaces.
* **Database & Security:** Firebase Authentication & Cloud Storage – Facilitates secure user onboarding and real-time state persistence.

### 🎯 Core Learning Impact
* **Foundations:** Differentiating needs vs. wants and establishing budgeting basics.
* **Mechanics:** Simulating compound interest, understanding inflation, and calculating savings growth.
* **Security:** Identifying modern financial scams, managing credit risks, and protecting personal data.

### ⚡ Development Ideology
Building clean, interactive systems that make education engaging and complex tools accessible to everyone. 💻
